Client-Server Model & Request Flow

HTTP operates as an asymmetrical request-response protocol across networked systems[cite: 206]. Communication involves two primary entities:

  • The User Agent (Client): Initiates communication by dispatching requests (e.g., web browsers, cURL)[cite: 206].
  • The Web Server: Awaits connections, processes requests, interacts with databases, and returns HTTP responses[cite: 206].

The Transactional Cycle

Step Action Description
1 DNS & Handshake Browser resolves domain to IP and establishes transport connection[cite: 207].
2 Request Transmission Client sends method, path, headers, and optional payload[cite: 207].
3 Server Response Server evaluates request, generates status code, and transmits payload[cite: 207].
