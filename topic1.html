Client-Server Model & Request Flow

HTTP operates as an asymmetrical request-response protocol across networked systems. Communication involves two primary entities:

  • The User Agent (Client): Initiates communication by dispatching requests (e.g., web browsers, command-line tools like cURL).
  • The Web Server: Awaits incoming connections, processes incoming requests, interacts with databases or file systems, and returns formatted HTTP responses.

Example HTTP Request Message

GET /index.html HTTP/1.1
Host: www.example.com
Accept-Language: en
User-Agent: Mozilla/5.0

The Transactional Cycle

Step Action Description
1 DNS & Handshake Browser resolves domain name to IP address and establishes reliable transport connection.
2 Request Transmission Client sends request message containing method, path, headers, and optional payload body.
3 Server Response Server evaluates request, generates status code, and transmits headers alongside resource payload.
