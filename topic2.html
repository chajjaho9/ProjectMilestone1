Milestones in Protocol Development

HTTP/0.9 (1991)

The one-line protocol. Supported only the GET method with no headers or status codes, transferring raw HTML over single-use TCP connections.

HTTP/1.0 (1996)

Introduced status codes, content-type headers, versioning strings, and basic caching directives, requiring new TCP handshakes per file.

HTTP/1.1 (1997)

Formalized in RFC 2068, adding persistent keep-alive connections, Host headers for virtual hosting, and advanced caching.

HTTP/2 (2015)

Standardized in RFC 7540, introducing binary framing, request multiplexing over a single TCP socket, and HPACK header compression.

HTTP/3 & QUIC

Shifts the transport layer from TCP to UDP, eliminating head-of-line blocking and providing instant 0-RTT connection establishment.
