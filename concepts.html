Essential Technical Concepts

  1. Stateless Principle: Each request is completely independent; servers retain zero recollection of previous requests, maximizing scalability[cite: 208].
  2. State Management: Overcoming statelessness using browser cookies, URL parameters, and JSON Web Tokens (JWT)[cite: 208].
  3. Protocol Stack: The hierarchical arrangement where HTTP sits on top of transport protocols like TCP or UDP/QUIC[cite: 209].
  4. Status Code Categories: Standardized numerical ranges (1xx, 2xx, 3xx, 4xx, 5xx) communicating request outcomes[cite: 211].
  5. Binary Framing Layer: Replaces plaintext messages in HTTP/2 with compact binary frames multiplexed over streams[cite: 214].
  6. Transport Layer Security (TLS): Encrypts web traffic within HTTPS to protect data against tampering and sniffing[cite: 216].
  7. Head-of-Line Blocking: A limitation in TCP where packet loss on one stream stalls subsequent data, resolved by QUIC/UDP streams[cite: 215, 220].
